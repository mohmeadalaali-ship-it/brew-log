## 💡 الفكرة من المشروع

في سيرفر القهوة، كل محصول له بوست خاص، وداخله يوثّق الناس محاولاتهم: الوصفة، الطحنة، الماء، الوقت، الطعم، والتعديل المقترح. الهدف نوصل لأقرب كوب ممتاز من أول محاولة، ونبني مرجع حقيقي للمجتمع.

المشكلة إن كتابة النموذج يدوي كل مرة تاخذ وقت، وكل واحد يكتبه بشكل مختلف. هذي الأداة تعطيك نفس القالب بنفس الترتيب كل مرة، وتحسب لك الأشياء اللي تتعب، وتقول لك أي تاقات تختار.

> **لا ترمي وصفة!** وثّق الكوب، وش صار، وش تعدّل.

تشتغل كاملة في المتصفح، بدون تسجيل دخول وبدون سيرفر.

## ✨ المميزات

| | الميزة | التفاصيل |
|:-:|---|---|
| 🏷️ | **عنوان تلقائي** | بصيغة `[المحمصة] المحصول — الطريقة` |
| 📋 | **قوائم جاهزة** | البلد، المعالجة، طريقة التحضير، الطاحونة، مع خيار "أخرى" |
| ⚖️ | **حساب النسبة** | تلقائي من الجرعة والناتج، مثل `1:16.7` |
| 🔧 | **تحويل الطحن لميكرون** | لأكثر من 60 طاحونة |
| 💧 | **الصبّات** | كمية بـ"مل" ووقت كل صبّة، مع إضافة وحذف |
| ⏱️ | **الوقت مباشر** | `1:20` أو `120` تصير `1:20`، و`45` تصير `0:45` |
| 😋 | **تقييم الطعم من 10** | الحلاوة، الحمضية، القوام، المرارة، النظافة |
| 🔁 | **وش يحتاج تعديل؟** | تختار للمحاولة الجاية |
| 🔖 | **صندوق التاقات** | يعرض لك التاقات اللي تختارها في ديسكورد |
| 📎 | **زر نسخ** | للنص الكامل أو العنوان لحاله |
| 🌙 | **وضع داكن وفاتح** | مع حفظ اختيارك |
| 🧹 | **حقول فاضية تنحذف** | من النص الجاهز تلقائي |

## 🚀 طريقة الاستخدام

| الخطوة | وش تسوي |
|:-:|---|
| **1** | افتح الموقع. |
| **2** | عبّ **بيانات القهوة**: المحمصة، المحصول، البلد، المعالجة، تاريخ التحميص. |
| **3** | عبّ **التحضير**: الطريقة، الأداة، الفلتر، الطاحونة، درجة الطحن، الماء، الحرارة، الجرعة، الناتج، الوقت الكلي. |
| **4** | أضف **الصبّات**: الكمية بالمل ووقت كل صبّة. |
| **5** | اكتب **وصف الطعم**، حرّك سلايدرات التقييم، واختر "وش يحتاج تعديل؟". |
| **6** | اضغط **نسخ العنوان** والصقه في عنوان البوست في ديسكورد، ثم **نسخ النص** والصقه في محتوى البوست. |
| **7** | اختر **التاقات** اللي ظهرت لك في صندوق التاقات. |

## 📝 مثال على الناتج

**عنوان البوست:**

```text
[DAK] Surf Jam — V60
```

**نص البوست:**

```text
المحمصة: DAK
المحصول: Surf Jam
البلد: إثيوبيا
المعالجة: مجفف
طريقة التحضير: V60
الطاحونة: K-Ultra
درجة الطحن: 3.0 (≈600 µm)
الماء: Volvic
الحرارة: 93°
الجرعة: 15 غ
الناتج: 250 غ
النسبة: 1:16.7
الوقت الكلي: 2:50

الوصفة:
- 50 مل | 0:45 | تفتيح
- 100 مل | 1:20

الطعم: حلاوة جميلة وفيه مرارة شوي
الحلاوة: 8/10
الحمضية: 3/10

وش يحتاج تعديل؟
- أخشن
```
